QuickLook.Plugin.FbxViewer 1.3.0
================================

安装：
1. 安装并运行 QuickLook 4.5.0 或兼容版本。
2. 在文件资源管理器中选中 QuickLook.Plugin.FbxViewer-v1.3.0.qlplugin，按空格。
3. 在 QuickLook 窗口中点击安装，然后退出并重新启动 QuickLook。
4. 选中 FBX 文件并按空格预览。

文件：
- QuickLook.Plugin.FbxViewer-v1.3.0.qlplugin：插件安装包
- QuickLook.Plugin.FbxViewer-source-v1.3.0.zip：完整源码
- preview.png：界面预览
- RELEASE_NOTES.md：版本说明
- SHA256SUMS.txt：安装包和源码包的 SHA-256 校验值

主要操作：
- Alt + 左键：旋转
- Alt + Shift + 左键：吸附到 90 度视角
- Alt + 中键 或 Ctrl + Alt + 左键：平移
- Alt + 右键 或滚轮：缩放
- Shift + 右键：调整灯光方向
- Alt + W：切换线框
- F：聚焦并重置视角

显示模式：材质、白模、漫反射、金属度、粗糙度。
